# Estimate

The original estimate is the time to build the story and review it, in Jira's format: `30m`, `1h`, `2h`, `4h`, `1d`, `2d`. Base it on what the observation found: the files to change, the tests to write and the number of Done when criteria. Round up to the next value of that scale. A story that needs more than `2d` is too big: split it before declaring it.
