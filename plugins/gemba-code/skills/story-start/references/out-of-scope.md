# Out of scope

A point of Out of scope comes from one of two sources: something the person said in the conversation, or a neighboring behavior of the same flow that you observed in step 3. A neighbor enters only when someone would expect it inside the story and no Done when criterion already answers it. A point that comes from neither source is not written. Order and dependencies between stories go in `Blocks` and `Relates` links, not here.

When no source produces a point, the section holds one item saying there is none, in the `Content:` language (`Ninguno.` in Spanish): `story.py` accepts it.
