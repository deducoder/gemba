# Time-box

The original estimate of a spike is its time-box: the working time with Claude the research may take before it answers, in Jira's format: `30m`, `1h`, `2h`, `4h`, `1d`. Base it on what the question needs to be answered: the sources to read and the comparison or test to run. Round up to the next value of that scale. Once the time-box is over the research runs no more experiments, so a question that needs more than `1d` is too broad: narrow it to the question the decision waits on.
