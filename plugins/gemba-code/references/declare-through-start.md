# Declare through a start

A work item declared through `story-start`, `spike-start` or `epic-start` is declared by that start, one at a time, with the Skill tool and a request that carries what the declaring skill gives it:

- What a start asks, such as an open decision, a split of the story or the plan of an epic, goes to the person: relay it and wait for the answer, then let the start finish and go on with the next work item.
- A work item its start does not create, because it names a bug, a spike, another story or an answer instead, is kept with what its start proposed, and the next one follows.
- A start's reply ends that work item, not the declaring skill: keep the key and the link of each work item it created.
