# Priority

A work item's priority is its urgency. Deduce it from its own content, never from links or other work items. When the content does not decide between two levels, take the lower one. A date or urgency the user gave moves it one level up; "it can wait" moves it one level down. Do not ask for it.

## Story

What happens if it is not built?

- **Highest:** nothing works without it.
- **High:** the central flow of its epic or the purpose of the project is not met.
- **Medium:** it changes what the user can do.
- **Low:** it changes only how something looks or feels.

## Bug

What happens if it is not fixed?

- **Highest:** data is lost, corrupted or exposed.
- **High:** it fails with no alternative in a flow the project exists for.
- **Medium:** it fails, but an alternative exists.
- **Low:** it does not affect results.

## Spike

What happens while it stays unanswered?

- **Highest:** work under way is stopped.
- **High:** a decision about the purpose of the project, or something with a date, waits on it.
- **Medium:** a decision about an improvement waits on it, and the work goes on.
- **Low:** nothing waits on it: it is exploration.
