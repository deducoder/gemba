# Out of scope

A point of Out of scope comes from one of two sources: something the person said in the conversation, or a neighboring behavior of the same flow that you observed before drafting. A neighbor enters only when someone would expect it inside the work item and no Done when criterion already answers it. A point that comes from neither source is not written. Order and dependencies between work items go in `Blocks` and `Relates` links, not here.

When no source produces a point, the section holds one item saying there is none, in the `Content:` language (`Ninguno.` in Spanish): the draft script accepts it.
